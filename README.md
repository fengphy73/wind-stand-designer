# 風力發電底座支架設計器 v1.1.2

KidWind 2026 亞洲聯賽（台灣版 AESEA v2.4）底座支架設計器。採用已核准的方案 D：5 mm 夾板雷切 50×50 指接方形空心柱、440×440×7 底板、三角補強、塔頂兩層板、3 寸全珠轉盤、偏航平台、尾翼，以及 3D 列印的加長輪轂與限位件。

靜態網頁。調參數之後會同時更新 3D 預覽、三視圖、偏航掃掠、安全係數圖、爆炸圖、雷切排版與估重。3D 預覽和 STL 用同一份 Manifold 網格。

## 預設

- 隔板只在方管上下兩端各一片，中間中空。
- 底板 440×440×7 mm，放得進市售 7 mm、450×900 的板。邊長仍可在 400–600 之間調整。
- v1.1 定案：3 寸轉盤夾在 130×130×7 木板裡。上木板鎖上框，L1／L2 鎖下框並套方管。尾桿改接加長到 270 mm 的齒輪下板（另檔，教具老師修正）。主軸離底板頂面 500 mm，輪轂絕對高 507 mm，葉長 415 mm。六角軸對角 7 mm。軸承轉軸版只是概念。
- 25 倍與 30 倍都可以。30 倍主軸再高 5 mm，塔頂高度不變。

計算方法與 `calcD.py` 相同。用原始假設（隔板 4、葉長 380、輪轂 480、塔頂 80）重算，4 m/s 安全係數是 2.74，與 calcD.json 一致。預設幾何改過之後，數字會跟著變，畫面上兩欄並排。

## 輸出

- 雷切依板厚分兩種市售板。7 mm 用 450×900 mm，排底板、上木板、下木板 L1、L2。5 mm 用 600×900 mm，排壁板、內隔板與備品、三角補強片、柱腳套框、尾桿、齒輪下板加長、尾桿導槽條、限位擋塊。板邊留 5 mm，零件間距 3 mm。預設參數各一張。放不下時頁面會寫出需要幾張，或哪個零件超出板材。請照實際尺寸匯入，不要另外縮放。
- 齒輪底板兩片各 5 mm，總厚 10 mm（厚度已量測）。下板才往尾端加長 80 mm 接尾桿，上板不加長。寬度、孔位、內框仍待確認。
- STL：加長輪轂、限位環、限位擋銷、尾桿座。
- 齒輪組用上木板的 4 顆 M4 鎖上，可以整組拆下。原齒輪組設計不改。若要在齒輪底板偏航軸開 Ø20 穿線，用另存的「教具老師修正」檔。

## 開發

```bash
npm install
npm test          # 計算對照、封閉網格、排版，以及無頭瀏覽器截圖
npm run build:pages   # 輸出到 docs/（相對路徑，之後若要 GitHub Pages 用 main /docs）
```

本版不要開啟 GitHub Pages。`docs/` 只是先備好。
