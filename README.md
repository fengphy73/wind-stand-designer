# 風力發電底座支架設計器 v1.1

給執行長的 KidWind 2026 亞洲聯賽（台灣版 AESEA v2.4）底座支架設計器。採用已核准的方案 D：5 mm 夾板雷切 50×50 指接方形空心柱、600×600 底板、三角補強、塔頂兩層板、3 寸全珠轉盤、偏航平台、尾翼，以及 3D 列印的加長輪轂與限位件。

靜態網頁。調參數之後會同時更新 3D 預覽、三視圖、偏航掃掠、安全係數圖、爆炸圖、雷切排版與估重。3D 預覽和 STL 用同一份 Manifold 網格。

## 預設（執行長目前的決定）

- 隔板只在方管上下兩端各一片，中間中空。
- 葉長自動取到剛好不超出 Ø100 cm 圓柱：430 mm（再長 5 mm 葉尖就會超出）。輪轂中心提高到 520 mm，葉尖才不會扣掉彎曲預留後碰到底板。最高點 985 mm。
- 25 倍與 30 倍都可以。30 倍主軸高 85 mm，同一輪轂高度下塔頂低 5 mm。
- v1.1 塔頂改成兩片 190×100 全長板，中間夾 3 寸轉盤。上層板的 12 個 M4 孔對齊齒輪底板，用 M4×12 鎖上。轉盤維持 45°，因為 0° 的螺帽會貼到方柱角。下層與上層同尺寸，兩層穿線開口中心都在偏航軸。

計算方法與 `calcD.py` 相同。用原始假設（隔板 4、葉長 380、輪轂 480、塔頂 80）重算，4 m/s 安全係數是 2.74，與 calcD.json 一致。預設幾何改過之後，數字會跟著變，畫面上兩欄並排。

## 輸出

- 雷切 SVG 兩張，各 900×600 mm，紅線切割、藍線雕刻。請照實際尺寸匯入，不要另外縮放。
- STL：加長輪轂、限位環、限位擋銷、尾桿座。
- 齒輪組是執行長自己的設計，這個設計器只標示安裝範圍與建議穿線孔，不改原檔。

## 開發

```bash
npm install
npm test          # 計算對照、封閉網格、排版，以及無頭瀏覽器截圖
npm run build:pages   # 輸出到 docs/（相對路徑，之後若要 GitHub Pages 用 main /docs）
```

本版不要開啟 GitHub Pages。`docs/` 只是先備好。
